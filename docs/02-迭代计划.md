## 分支与发布

- `main`：仅接受来自 `develop` 的 PR；每次合并打 tag
- `develop`：日常集成分支
- `feature/<name>`：单功能分支，完成后 PR 到 `develop`
- 发布流程：
  1. 更新 `CHANGELOG.md`（Added / Changed / Fixed）
  2. `npm run build` 通过
  3. 部署 Qoder Sites 并验证公网
  4. 合并 `develop` → `main`
  5. 打 tag：`git tag v0.x.0 && git push --tags`
  6. 创建 GitHub Release，附演示链接与变更说明

## 提交规范

```
feat(scope): 新功能
fix(scope): 修复
docs: 文档
refactor: 重构
chore: 构建/工具
```

## 风险与决策记录

- 语音：v1 只做语音消息，实时语音仅近场（物理带宽决定）
- 平台：Android 优先，iOS 作终端 + 外接模块
- 频段：比赛用 433 MHz 认证模块小功率；产品化前做 SRRC 与频段合规评估
