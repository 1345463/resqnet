# 电脑端（Electron / 免安装 exe）

## 组成

- `desktop/`：Electron 壳，本地加载管理台，放行 Web Serial
- `firmware/usb-bridge/`：ESP32 + SX1262，LoRa ↔ 串口 JSON
- 管理端设置里可选「USB 串口」数据源

## 运行

```bash
cd console && npm install && npm run build
cd ../desktop
npm install      # 国内：ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
npm start
```

## 打 exe

```bash
cd desktop && npm run package
# 产物：release/ResQNet/ResQNet.exe（免安装）
```

未签名，首次运行 SmartScreen 选「更多信息 → 仍要运行」。

## 接 LoRa

1. 烧 `firmware/usb-bridge`（115200）
2. 插 USB
3. 设置 → 数据源 → USB 串口 → 连接串口

## 与 WebSocket 网关的区别

| | USB 串口 | WebSocket 网关 |
|---|---|---|
| 硬件 | usb-bridge | gateway |
| 连接 | USB 线 | WiFi/热点 |
| 适合 | 指挥所单机 | 多电脑 + 手机 BLE |
